# Agent guidance

- Read repository documentation, configuration, and applicable nested instructions before editing.
- Respect the selected language, framework, and established conventions. This template selects none.
- Keep changes scoped to the requested task; avoid unrelated refactoring, dependencies, and configuration.
- Write readable, maintainable, secure code and update relevant documentation.
- Run relevant available checks before committing. Report limitations honestly; never invent tests, execution results, or functionality.
- Never commit secrets or sensitive data; review staged changes.
- Preserve unrelated work. Avoid destructive operations and history rewriting without explicit authorization and justification.
- Add automation only when requested or justified by project needs; this template has no automatic CI.

These are plain-language instructions. Agent discovery and configuration differ by tool; consult the selected assistant's documentation if it does not read this file.
